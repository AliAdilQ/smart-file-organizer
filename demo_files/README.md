# Isolated test files

Run `python generate_demo.py` from the repository root. It creates eleven text-only
fixtures in `sample_downloads/` and prints the absolute folder path for the organizer.
The extensions are illustrative: these are **not real PDFs, images, archives, or
videos**. The generator never overwrites an existing file. Sample files and all
organized output are ignored by Git. No real personal folders are used.
